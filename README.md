# Preregistration: revision plan D and journal extension J

Two analysis plans for *Validating LLM User Simulators for Information Cocoon Research*, written before any new run. The Zenodo archive of this repository's release is the registration; its timestamp is the registration time.

- `prereg_d.md`: Plan D, which addresses the review of TCSS-2026-09-1681 (click-count control, corrected swap operator with paired and training-set targets, fitted reference clickers on random slates, multi-seed loops, seed-0 replay, AUC references).
- `prereg_j.md`: Plan J, which adds a second dataset (EB-NeRD small), a third model family (Llama-3.1-8B-Instruct), subcategory metrics and an eight-variant prompt sensitivity check.
- `plan_D_en.md`, `plan_J_en.md`: English translations. The Chinese originals govern.

Earlier registered verdicts (A2, R3 not supported) and the 10% and 0.05 lines are unchanged. Any later change is appended to the plan file as a dated amendment and published as a new release.
